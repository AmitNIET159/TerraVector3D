# BhuDrishti Geospatial AI Module

## Purpose
AI-assisted geospatial processing module for BhuDrishti 3D. Prototype decision-support system for GeoJSON normalisation, floor-plan image analysis, point-cloud floor-level detection, confidence scoring, and human-verification output. All outputs require authorised human verification.

> **Disclaimer**: All outputs are prototype decision-support only. This module never claims legal ownership validation or final cadastral approval. Every output includes `human_verification_required: true`.

## Quick Start
```bash
pip install -r requirements.txt
python -m src.cli run-all
```

## CLI Commands
- normalize: `python -m src.cli normalize --parcel input/sample_parcel.geojson`
- analyze-floor-plan: `python -m src.cli analyze-floor-plan --image input/sample_floor_plan.png --metres-per-pixel 0.05`
- detect-floors: `python -m src.cli detect-floors` (auto-generates synthetic PLY)
- confidence: `python -m src.cli confidence --source-quality 0.85 --image-quality 0.70 --pointcloud-density 0.80`
- generate-synthetic-pointcloud: `python -m src.cli generate-synthetic-pointcloud --output output/synthetic_building.ply`
- run-all: `python -m src.cli run-all --parcel input/sample_parcel.geojson --floor-plan input/sample_floor_plan.png`

## Output Schema Overview
- `normalized_parcel.json`: Normalized parcel boundaries. Fields: `parent_ulpin`, `footprint`, `area_sqm`, `bounding_box`, `coordinate_reference`, `source_type`, `confidence_score`, `warnings`, `human_verification_required`, `disclaimer`.
- `floor_plan_suggestions.json`: Suggested room geometries from floor plans. Fields: `parent_ulpin`, `coordinate_reference`, `image_path`, `metres_per_pixel`, `proposed_units`, `warnings`, `human_verification_required`, `disclaimer`.
- `pointcloud_floor_suggestions.json`: Suggested floor levels from point cloud data. Fields: `parent_ulpin`, `coordinate_reference`, `method_used`, `detected_slab_elevations_m`, `estimated_floor_height_m`, `suggested_levels`, `warnings`, `human_verification_required`.
- `confidence_result.json`: Combined confidence score for the analysis. Fields: `overall_score`, `confidence_level`, `factor_breakdown`, `available_sources`, `missing_sources`, `explanation`, `warnings`, `human_verification_required`.

## Architecture
- `geojson_normalizer.py`: GeoJSON validation, CCW winding, local-metre translation
- `floor_plan_analyzer.py`: OpenCV contour detection, room/unit boundary proposals
- `pointcloud_floor_detector.py`: Histogram + RANSAC + DBSCAN floor detection
- `confidence_engine.py`: Weighted multi-source confidence scoring
- `synthetic_pointcloud_generator.py`: Deterministic test data generation

## Limitations
- Floor-plan analysis uses classical image processing only; complex architectural drawings may produce poor results
- Point-cloud detection works best with clean, dense slabs; noisy or sparse data reduces accuracy
- No real cadastral data, no GPS/GIS coordinates (local metres only)
- Vertical IDs are NOT generated by this module (see bhudrishti_identity_rights)
- All confidence scores are estimates, not guarantees
